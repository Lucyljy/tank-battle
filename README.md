# 坦克大战 · Tank Battle

一个使用纯 HTML / CSS / JavaScript（Canvas）实现的经典「坦克大战」（Battle City）网页小游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 🎮 玩法

- 控制你的坦克消灭所有敌军坦克，并**保护你的基地（旗帜）**。
- 基地被摧毁、或生命耗尽，游戏结束。
- 每消灭一个敌人可获得分数；某些闪烁的敌人会掉落道具。

## 🕹️ 操作

| 按键 | 功能 |
| --- | --- |
| `W` / `A` / `S` / `D` 或 方向键 | 移动 |
| `空格` | 射击 |
| `P` | 暂停 / 继续 |
| `M` | 静音 |
| `Enter` | 开始 / 下一关 |

## 🧱 地形

- 🟫 **砖墙** — 可被子弹摧毁
- ⬜ **钢墙** — 无法破坏（火力满级可摧毁）
- 🟦 **水面** — 坦克无法通行，子弹可飞过
- 🟩 **草丛** — 可隐藏坦克
- 🚩 **基地** — 被击中则游戏失败

## ⭐ 道具

- ⭐ **星星** — 提升火力等级（更快 / 更多子弹 / 摧毁钢墙）
- 🛡️ **护盾** — 短时间无敌
- ❤️ **生命** — 增加一条命
- 💣 **炸弹** — 消灭场上所有敌人

## 🚀 运行

方式一：直接用浏览器打开 `index.html`。

方式二（在线试玩）：本仓库已启用 GitHub Pages，访问：
`https://<你的用户名>.github.io/tank-battle/`

方式三（本地静态服务器）：
```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```
